# TraceDeck

Project reference and durable operating context for AI-assisted work.

The durable project rules are in `AGENTS.md`. Phase 1 findings and the coding-agent work breakdown are separate so implementation agents can consume them without redoing the investigation.

## Documentation map

- `AGENTS.md` — project instructions and implementation constraints
- `notes.md` — confirmed technical decisions
- `backlog.md` — planned work
- `backlog/log.md` — completed-work log
- `implementation-plan.md` — ordered implementation packets and phase gates
- `reports/phase-1-analysis.md` — Codex integration findings, corrected architecture, schema, and limitations
- `reports/technical-constraints.md` — measurable performance and resource budgets
- `reports/` — research findings and supporting source notes
